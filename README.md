# Sobre o projeto

A base de dados da Olist foi escolhida para compor este projeto por apresentar informações variadas sobre um ambiente real de comércio eletrônico, permitindo explorar diferentes perspectivas de negócio e consolidar os conhecimentos adquiridos ao longo da minha formação como Analista de Dados.

O principal objetivo deste projeto é aplicar e aprimorar as ferramentas consideradas essenciais neste primeiro momento da minha jornada: **SQL, Python, Excel e Power BI**, utilizando os dados como base para análises, geração de indicadores e desenvolvimento de soluções orientadas a negócios.

A proposta é ir além da exploração dos dados, buscando atuar como uma analista de dados diante de problemas reais, formulando perguntas de negócio e utilizando os dados para encontrar respostas que apoiem a tomada de decisão.

As análises terão como foco temas como:

* Logística e desempenho das entregas;
* Satisfação dos clientes;
* Análise de vendas;
* Comportamento dos consumidores;
* Campanhas de marketing;
* Outros aspectos relacionados ao negócio.

Além do desenvolvimento técnico, este projeto também tem como objetivo aprimorar minha capacidade de **storytelling com dados**, comunicação de resultados e apresentação de insights para diferentes públicos, como equipes e gestores.

##  Objetivos

* Explorar e compreender a estrutura dos dados disponíveis no dataset da Olist.
* Realizar análises utilizando SQL para extração, organização e investigação dos dados.
* Desenvolver processos de tratamento, limpeza e análise de dados utilizando Python.
* Construir dashboards utilizando Excel e Power BI para acompanhamento de indicadores.
* Gerar insights de negócio a partir dos dados analisados.
* Desenvolver análises relacionadas às áreas de:

  * **Vendas:** compreender desempenho comercial, faturamento, produtos e comportamento de compra.
  * **Logística:** analisar prazos de entrega, desempenho operacional e possíveis gargalos.
  * **Experiência do cliente:** avaliar satisfação, avaliações e fatores que influenciam a percepção do consumidor.
  * **Marketing:** explorar comportamento dos clientes e oportunidades de segmentação.
* Praticar a formulação de perguntas de negócio e a apresentação de resultados por meio de storytelling com dados.
* Consolidar conhecimentos técnicos e construir um projeto de portfólio em Análise de Dados.
